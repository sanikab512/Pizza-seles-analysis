# Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using SQL queries in MySQL to understand sales performance, revenue, and popular pizza types.

## Tools Used
- MySQL
- SQL

## Key Analysis
- Total revenue calculation
- Top 3 pizza types by revenue
- Daily pizza order analysis
- Revenue by pizza category
- Average pizzas ordered per day
- Cumulative revenue analysis

## Skills
SQL Queries, JOINs, GROUP BY, Aggregate Functions, Subqueries, and Data Analysis.
